# 현재 상태

마지막 갱신 2026-11-22

## 배포 구성

- Python 표준 라이브러리 기반 CLI, 오프라인 HTML, 로컬 테스트와 개발 문서를 포함한다.
- 루트 설정 예시와 개인 설정·수집 결과는 Git에서 제외한다. README의 JSON을 참고해 개인 설정을 만든다. 테스트에는 루프백 fixture를 사용한다.

## 배포 사본 검증

Linux Python 3.12.3에서 unittest 216개 중 214개가 통과했고, 환경의 루프백 소켓 제한으로 두 테스트를 건너뛰었다.
설치 없이 CLI help, 공개 설정과 seed의 오프라인 plan, 선택적 Node DOM 검사 두 종류가 통과했다.

## 최신 변경

- 페이지·호출 관계 탭에서 함수의 호출자·피호출자, 변수 사용 위치와 주소식 의존을 탐색한다.
  스크립트와 선언 위치를 기준으로 동명 심볼을 구분한다.
- 콜 그래프 예제는 tests/fixtures/assets/callgraph-demo.js다. 원본 파일·변수 값은 보고서에 넣지 않는다.
  저장된 구버전 결과는 당시 수집한 위치와 참조를 표시한다. 파일 간 호출과 동적 디스패치는 미확인이다.

## 구현 상태

Phase 1과 Phase 2의 MVP 코드 및 테스트를 구현했다. 설치 없는 CLI, 안전한 수집 경로,
정적 분석, 결과 저장은 동작한다. **실제 루프백 HTTP 통합 성공 조건은 환경 제한으로 미검증**이다.
2026-11-18 사용자 요청으로 로컬 웹 서버·작업공간 기능을 롤백했다. 현재는 CLI와 오프라인
HTML 보고서만 제공하며 웹 서비스 기능을 임의로 다시 도입하지 않는다.
같은 날 단순 const·별칭 추적을 추가했다. `fetch(url)`의 문자열 조합을 따라가며 미확인 값은
이유와 출처를 남긴다. 이후 D021에서 명시적 모듈·문서 참조의 반복 탐색을 추가했다.
웹 서비스·JS 실행·자동 API 호출은 추가하지 않았다.

완료 항목:

- 루트 Python 패키지, JSON 설정/고정 상한, help/plan/scan/dry-run/report/analyze-js.
- 다중 시작 URL: JSON seed_urls, plan/scan --seeds-file, 최대 50개 시작점을 깊이 0으로 BFS.
  파일/형식/범위 사전 검증, 중복 제거, 마스킹, 공통 요청/페이지 예산 적용.
- 승인 전 네트워크 차단, 정확한 origin 검증, 비공개 주소 차단, DNS 검증 후 IP 고정 연결.
- 완료 후 간격, 요청 예산, GET 전용, redirect 재검증, TLS 기본 검증, backpressure 중단.
- 사용자 지정 Chrome/158.0.0.0 User-Agent를 config.py에서 관리하고 모든 HTTP에 적용.
  robots 평가 식별자는 WebRecon/0.1로 분리해 기존 도구 전용 규칙을 유지한다.
- robots 404/410 부재 시 수집 계속, 그 외 실패 시 중단. 보수적인 Disallow 및 간격 처리.
- robots_html_policy=continue의 제한적 200 HTML 예외: 정책 미확인을 기록하고 seed/BFS/JS 수집 계속.
  배포 예시와 기본 정책은 stop을 사용한다.
- robots_checks: 상태·MIME·전송·잘림·본문 형식 등 구체적인 실패 코드와 원문 없는 특징 기록.
  터미널에 중단 원인·상태·타입·세부 오류를 표시하고 기존 JSON도 저장 메타데이터로 재분석.
- 이미 수신한 robots HTML을 별도로 파싱해 링크·폼·인라인 JS와 동적 패턴을 추출.
  response_documents에 마스킹된 구조를 저장하고 URL/API/패턴 목록에 포함한다. 추가 요청은 없다.
- 입력 URL의 응답 수신·요청 실패·차단·미방문 및 입력만 있는 후보/콘텐츠 발견/응답 경로 집계.
  큐 후보의 최종 disposition 갱신, initial_disposition 보존, HTML 파싱 수 분리.
- robots Allow/Disallow 선언의 별도 기록, 출처·줄·시각·마스킹, 패턴과 URL 후보 구분.
- url_list/api_list 저장 및 report --list urls|apis --group-by domain|path 오프라인 출력.
- 실제 응답 메서드와 폼/JS 선언 메서드 분리. 메서드 근거가 없으면 unknown.
- 인라인 및 승인 범위 .js/.mjs의 정적 URL/메서드 추출. JS 실행·발견 API 호출 없음.
- fetch/axios/XHR 형태의 단순 const·별칭·결합·템플릿 추적 및 report --list patterns.
  호출·선언 위치, 해석 상태·미확인 이유를 JSON/HTML에 기록한다. 미확인 base와 변수는
  자리표시자로 보존하고, 문자열로 완성된 주소만 URL/API 후보에도 포함한다. 모두 기록 전용이다.
- JS 호출 진단: 지원 형태의 검출/완료/부분/미확인/제외·중복 수, 이유·위치, 토큰화 오류·상한 구분.
  상세·진단 단위 수를 제한하고 생략 수를 표시한다. 검출하지 못한 호출의 수는 알 수 없다.
- 주소 패턴에 연결된 변수 목록: 출처·인라인 순번·선언/범위를 구별하고 패턴·이유를 연결한다.
  HTML에 패턴 해석 상태, 변수 해석 상태/출처 필터와 JS 진단 상세를 추가했다.
- analyze-js --input --base-url: 로컬 UTF-8/BOM 일반 파일 하나(최대 1MiB)를 DNS/HTTP 없이 분석해
  JSON/HTML을 저장한다. 입력 원문·경로·파일명은 저장하지 않고 승인 범위는 미평가로 표시한다.
- 일반/hex/Unicode 문자열 이스케이프와 단순 문자열 괄호 식 지원. 함수/산술 실행은 하지 않는다.
- 실제 응답 MIME 기반 HTML/JS 분석, JS 모듈/페이지 이동/iframe의 제한적 재귀 탐색,
  JS 체인 깊이·출처/위치 기록 및 오류 응답의 기록 전용 분석.
- BFS 및 요청/페이지/깊이/큐/응답/추출 제한, URL 재요청 방지.
- HTML 제목/링크/폼/필드/참조/메타 분석, 경로별 엔드포인트 및 출처/미확인 항목.
- 근거 기반 공격표면 후보/기술 단서, 민감 값 제거, JSON 저장 및 오프라인 재분석.
- 단일 오프라인 HTML 보고서: scan은 JSON 뒤에 자동 저장, report --format html로 기존 자료 변환.
  엔드포인트 검색/도메인·분류·응답/선언 메서드·방문 상태·범위 필터, 출처·입력 이름 상세,
  파일 참조 URL·타입·상태/MIME/크기, 페이지·폼, 동적 패턴, 요청·robots/실패 진단을 표시한다.
  네트워크 없이 동작하며 HTML 이스케이프·고정 스크립트 CSP 해시·텍스트 URL을 적용했다.
- 로컬 fixture, 메모리 HTTP 테스트, 별도의 실제 루프백 통합 테스트.
- AGENTS.md와 설계·명세·보안·결정·사용법 문서.
- 주요 Python 파일 16개에 판단 이유·데이터 계약·안전 경계의 한국어 주석/docstring을 보완했다.
  docs/DEVELOPMENT.md에 실행 흐름, 기능별 수정 위치, JS 파서 예제, 테스트/디버깅/인계 절차를 작성했다.

## 다음 개발 작업

앞서 제안한 네 가지 구현 작업과 사용법·개발 가이드 갱신을 완료했다. 추가 사용자 결정을 기다리는
사항은 없다. 다음 세션은 [DEVELOPMENT.md](DEVELOPMENT.md)의 재현 예제로 시작하고, 아래의
환경 의존 검증을 우선한다. 새로운 기능은 실제 누락 사례가 생기면 최소 fixture로 재현해 범위를 정한다.

환경 제한으로 남은 검증:

- 소켓 사용이 허용된 로컬 환경에서 필수 unittest의 실제 HTTP 테스트 2개를 완료한다.
  README의 fixture 서버/scan으로 JSON과 HTML 결과를 확인한다.
- 브라우저에서 검색·필터·상수 근거 표시·긴 경로·작은 화면·인쇄 가독성을 확인한다.
  정적 구조·DOM 모의 테스트까지 완료했으며 실제 브라우저 화면은 미검증이다.
- Windows·Linux/WSL2·Python 3.10 이상 실행 조합과 실제 로컬 TLS를 확인하고 실제 결과만 기록한다.
  필요하면 느린 응답 fixture로 전송 경계를 보강한다.

표준 라이브러리·요청 제한·민감정보 처리 회귀를 유지한다. 수동 변수 치환·브라우저 실행·
로컬 웹 서비스 재도입은 이번 구현 범위에 포함하지 않는다.
